# 캠핑 짐 관리 v1

기능
- 아이템 등록/수정/삭제
- 카테고리, 가방/박스, 집 보관 위치, 수량, 메모
- 항상 챙김 설정
- 이번 캠핑 물품 선택
- 챙김 체크와 진행률
- 가방별 / 보관 위치별 / 카테고리별 보기
- 캠핑 후 체크 초기화
- JSON 파일로 백업/공유, 가져오기
- 브라우저 localStorage에 저장
- PWA 설치 가능

실행
1. 폴더에서 `python -m http.server 8000`
2. 브라우저에서 `http://localhost:8000`
3. 휴대폰에서 쓰려면 정적 웹호스팅(GitHub Pages, Netlify 등)에 올리거나 같은 Wi-Fi에서 PC의 IP:8000으로 접속
4. Android Chrome에서 '홈 화면에 추가' 또는 '앱 설치'를 선택

파일만 직접 열어도 기본 기능은 동작하지만 PWA 설치/오프라인 캐시는 웹서버 환경이 필요합니다.
